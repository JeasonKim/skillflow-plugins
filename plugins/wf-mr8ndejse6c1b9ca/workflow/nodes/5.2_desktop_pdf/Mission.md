## 节点目标

基于 4.1 完成的完整逐字稿，制作一份适合电脑阅读的 PDF。PDF 应保留完整逐字稿主体内容，重点优化版式、目录、页眉页脚、章节层级、引用和长文阅读体验。

## 输入范围

- 4.1 输出的完整逐字稿 Markdown。
- 4.1 的讲话人姓名来源说明、术语说明、图片来源和质量核查记录。
- 上游可用的标题、场合、时间、章节或分段索引。

## 排版要求

- 面向电脑阅读，优先考虑 A4 或接近桌面阅读比例的页面尺寸。
- 提供清晰封面、目录、正文层级、页码和必要的来源说明。
- 对超长逐字稿，应保证目录可导航，章节层级稳定，分页不破坏讲话人段落和重要引用。
- 字号、行距、页边距和段落间距应适合长时间阅读，不做手机小屏优化。
- 若包含图片，图片应清晰、位置合理，并保留图片说明或来源说明。

## 内容边界

PDF 应基于 4.1 完整逐字稿，不得改写成摘要版、删节版或只保留重点版。可以为 PDF 阅读体验添加封面、目录、页眉页脚、章节编号和附录说明，但不能新增无依据内容。若因 PDF 体积或工具限制必须拆分文件，应记录原因，并提供清晰的卷册顺序；默认仍优先输出单个 PDF。

## 输出要求

输出适合电脑阅读的 PDF 文件。若生成中间 HTML、CSS 或 Markdown 排版稿，应一并列入交付清单。记录 PDF 生成工具、关键参数、已知限制和与 4.1 完整逐字稿的一致性说明。
