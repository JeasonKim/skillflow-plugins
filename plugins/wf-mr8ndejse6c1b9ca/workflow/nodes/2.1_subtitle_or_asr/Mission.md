## 节点目标

基于已确认的视频输入获取可处理的源语言文本。该节点必须兼容多种网址来源：YouTube 链接、其他视频平台页面、普通网页中的嵌入视频、播放器页、iframe 嵌入、HTML5 video/audio 标签、m3u8/mpd 流、视频或音频直链，以及用户提供的本地/云端素材路径。

## 输入兼容范围

- YouTube 链接、其他视频平台页面、普通网页中的嵌入视频和播放器页。
- iframe 嵌入、HTML5 video/audio 标签、m3u8/mpd 流、视频或音频直链。
- 用户提供的本地素材路径、云端素材路径或上游记录的候选媒体来源。
- 来自 1.1 Context backlog 的候选输入。backlog 中的 `episodeUrl` 可能是节目单集页面、官网文章页、播客平台页面、YouTube 链接，也可能是 RSS enclosure 提供的音频直链；不要默认它一定是普通网页视频页。

## backlog 输入处理

如果输入来自 `Context/data/podcast_episode_backlog.jsonl` 或 `Context/data/podcast_episode_backlog.md`，应优先保留 backlog 中的 `podcastName`、`episodeTitle`、`episodeUrl`、`episodeId`、`canonicalKey`、`source` 和 `publishedAt` 等来源信息。

对 backlog 输入，本节点的职责是判断最终可处理媒体源到底是什么：网页页链接、RSS enclosure 音频直链、YouTube 链接、播客平台页面、官网播放器、m3u8/mpd 流、音频文件直链或其它媒体源。若 `episodeUrl` 本身已经是可转录音频直链，可以直接按音频来源处理，不必强行回到网页视频探测路径。

## 网页视频源探测

处理任意网页时，应先识别页面中是否存在可处理的视频或音频来源，记录原始 URL、规范化 URL、页面标题、域名、嵌入来源、播放器来源、视频标题或可用元信息。可优先使用 yt-dlp 等成熟工具尝试解析原始 URL、嵌入 URL、播放器 URL 或媒体直链；必要时再结合页面源码、结构化数据、meta 信息、iframe、video/audio 标签、network 线索或浏览器可见信息定位真实媒体来源。不要仅依赖网页手工复制或不稳定的页面解析，也不要在未记录依据的情况下假定页面没有视频。

若任务需要使用 yt-dlp，但任务环境没有可用的 yt-dlp，应在权限允许范围内准备可执行工具，再继续探测和处理；不要仅因缺少 yt-dlp 就终止节点。安装或准备方式、版本、路径或失败原因应写入工具记录。

探测阶段只确认可抓取性、媒体来源和必要条件，不要一开始就下载完整视频。对活动页、直播页、回放页或课程页，不应只查找静态 `.mp4` 链接；应按“页面静态源码 → 播放器初始化参数 → 运行时 API → 浏览器网络请求”的顺序探测视频源。若能定位取源接口，应记录接口 URL、请求参数、返回状态和是否需要鉴权。

## 字幕和转录优先级

处理 YouTube 视频时应优先使用 yt-dlp 等工具读取视频元信息、字幕列表、真实字幕和自动字幕。对其他 yt-dlp 支持的平台，也应优先检查平台字幕、自动字幕、章节、标题、作者、发布时间等元信息。若字幕不可用，再下载或提取音频，并优先使用 Skill Flow 环境提供的内置转写能力；若不可用，再降级到任务环境可用的本地或外部 ASR/TTS 完成转录或必要的语音处理。

## Bilibili 视频处理

处理 Bilibili 视频时，应优先检查视频元信息、可用字幕、自动字幕、分 P、合集、标题、简介、UP 主和发布时间。B 站高画质视频格式通常需要会员 Cookie 或登录态，不应因为高画质视频流受限就直接判定无法处理。若任务目标是获取逐字稿，音频轨通常比高画质视频流更容易取得，可优先尝试获取音频轨或可转录音频来源。

## 超长视频处理

遇到超长视频时，不要把整段音视频一次性提交给 ASR 或一次性生成转录。若视频时长超过 90 分钟，或预计转录文本明显超过单次稳定处理范围，应默认采用分段策略：优先按章节、议程、演讲题目、静音点或播放器章节切分；若没有可靠章节信息，再按 10-30 分钟固定时长切分。

分段转录时，每段都应保留段号、时间范围、源媒体路径或源 URL、使用的字幕/ASR 方式、失败和重试记录。分段只用于稳定获取源文本，不改变最终交付目标；下游仍需要合并为完整连续逐字稿。

## 登录态和访问限制

遇到登录、年龄限制、地区限制、会员限制、反爬限制、动态加载、跨域嵌入或字幕访问限制时，应按任务环境可用方式使用 cookies 文件或等效认证材料，并记录限制类型、尝试路径和失败原因，不泄露敏感内容。若页面需要登录态才能获取视频源，节点应尽量拉起浏览器登录流程，让用户在浏览器中完成登录；不要要求用户手动复制 cookies，除非自动登录流程不可用。

## 输出要求

该节点输出原始字幕或转录文本、可追溯时间信息、工具使用记录、URL/媒体来源解析记录和获取方式说明，不进行中文翻译、内容清理、摘要或文章化改写。若采用超长视频分段策略，应输出分段索引、各段源文本路径和合并顺序说明。
