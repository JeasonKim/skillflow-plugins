1. [Markdown 成稿] 提供一份完整、可读取的中文 Markdown 逐字稿文件。
2. [逐字稿性质] 对话、访谈、播客、演讲和会议类内容保留逐字稿主体结构，不是第三人称综述、摘要或观点文章。
3. [完整性] 最终稿覆盖上游完整清理版源稿的主要时间段、自然章节、发言人和问答轮次，没有因内容过长而省略主体段落。
4. [分批记录] 长内容提供子 agent / subagent 分批记录，包含每批输入范围、输出文件、不确定项和覆盖说明。
5. [合并一致性] 最终稿统一标题层级、讲话人标签、术语写法、段落风格和来源说明。
6. [讲话人保守] 无法确认具体姓名时使用保守标签，并列出不确定原因；最终稿不出现“Speaker 1”“Speaker 2”或同类英文泛称。
7. [无脚本化成稿] 处理说明记录正文语义编辑由 agent 或子 agent / subagent 完成；脚本仅用于拆分、统计、检查或清单整理等辅助环节。
8. [扩写边界] 扩写内容能追溯到上游源稿含义或任务要求，没有新增无依据事实、数据、观点或结论。
9. [质量核查] 质量核查覆盖漏译、错译、口水词残留、时间戳残留、黑话堆叠、讲话人混淆、无依据增补、缩略和风格漂移。
10. [语音处理来源] 若上游文本来自语音转录或语音处理，交付说明记录内置转写能力优先尝试情况，或任务环境可用 ASR/TTS 降级原因。
11. [交付清单] 列出最终 Markdown、处理说明、分批记录、质量核查记录和关键中间文件路径。
