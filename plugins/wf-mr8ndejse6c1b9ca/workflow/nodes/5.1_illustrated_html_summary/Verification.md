1. [HTML 文件] 提供一个可在浏览器打开的 .html 文件。
2. [完整逐字稿保留] 4.1 完整逐字稿仍作为独立交付存在，HTML 没有覆盖或替换它。
3. [HTML 结构] HTML 包含标题、导读、主要章节、视觉模块、来源说明和必要的交付说明，不是图片或文字堆砌页。
4. [基于 4.1] HTML 的观点、事实、人名、数据、引用和结论均可追溯到 4.1 完整逐字稿或上游元信息。
5. [深度总结] HTML 是深度总结阅读版本，不是极简摘要、三分钟导读或营销海报页，也没有删除或覆盖 4.1 的完整逐字稿交付。
6. [有效字数] 对 90 分钟以上或多报告视频，除非任务明确要求极简版，HTML 有效正文不少于 12000 个中文字符；若低于该阈值，必须说明用户明确要求或源内容确实不足。
7. [章节覆盖] 每个主要报告或自然章节均有独立展开，包含讲者身份、核心问题、关键观点、关键例子或数据、与主线的关系。
8. [圆桌信息量] 圆桌按问题展开，保留不同嘉宾观点、共识和分歧；不得压缩成几个泛泛结论。
9. [非空泛] 主体内容不得只保留标题级观点、口号式总结或空泛启发；应保留具体论证、例子、数据、场景和代表性表达。
10. [章节组织] 若源内容包含多个自然章节或演讲人，HTML 按自然语义组织，而不是机械按固定字数、固定时间或视觉模块切块。
11. [图片记录] 每张图片都有文件路径、alt 文本、用途说明和来源或生成提示词。
12. [图片相关性] 图片服务于具体章节理解，不是纯装饰图；图片和文案没有新增逐字稿中无依据的人物、场景、数据、结论或现场细节。
13. [生图工具记录] 若生成图片，记录使用的任务环境可用图片生成、绘图或本地替代工具；若某能力不可用，说明不可用原因、替代工具名称和关键参数。
14. [压缩比例说明] 提供 4.1 正文字数、HTML 有效正文字数、压缩比例和各章节覆盖表；若压缩导致关键例子、数据、分歧或论证链丢失，则不通过。
15. [可读性] HTML 在桌面和移动浏览器中结构清晰，图片路径有效，样式不依赖私有外部服务。
16. [交付清单] 列出 HTML、图片资源、图片说明、来源说明、信息量说明和工具记录的文件路径。
17. [图文节奏] HTML 不是文字后面堆几张图，而是图文交替阅读；长文中应持续出现信息图、结构图、观点图或视觉解释模块。
18. [图片有效性] 图片必须解释具体观点、结构、流程、对比关系或章节主线；纯装饰图、抽象氛围图、无信息结构概念图、机器人摆拍图、假 UI、假仪表盘或未来控制室不计入有效配图。
19. [信息图质量] 大模型生成的信息图应具备明确结构、节点、层级、关系和内容指向；关键中文信息应在 HTML 正文、图注或配套说明中同步出现，不能只存在于图片里。
20. [章节视觉覆盖] 多报告、多嘉宾或圆桌内容，应围绕主要章节设计多个视觉模块，而不是只生成少量泛泛配图。
