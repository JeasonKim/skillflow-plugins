# 播客更新检查来源

本文件用于记录用户关注播客的真实更新来源。它不是节目排名报告，而是给 workflow 面板小管家、1.1 输入接收节点和 6.1 归档节点使用的“去哪查更新”参考表。

本版已把 42 档播客全部补上真实来源。来源优先级是：

1. Apple Podcasts 官方节目页。
2. 官方 YouTube 频道或节目母频道。
3. 官方网站或官方承载页。
4. RSS feed。

本版已补齐 RSS。需要批量自动检查更新时，优先使用 `podcast_watch_sources.jsonl` 中的 RSS；需要人工核验时，再看 Apple / YouTube / 官网。

## 核验说明

- 核验日期：2026-06-27。
- Apple Podcasts 链接：42/42 已连通检查通过。
- 官网链接：42/42 已填写；少数节目使用官方承载页或机构节目页。
- RSS 链接：42/42 已通过 Apple Podcast Lookup 或节目 feed 反查补齐。
- YouTube 链接：42/42 已填写至少一个可用 YouTube 来源；如果不是独立节目频道，则在备注中标明为母频道、节目 playlist、主持人频道或稀疏频道。
- 没有稳定独立 YouTube 的节目，不再留空；只要能找到节目相关的 YouTube 来源，就补入可用于人工检查更新的链接。
- `我关注的播客清单.md` 里的 `cite`、`turn...` 不能当真实 URL。
- 本文件只说明去哪查更新，不表示自动创建 task。
