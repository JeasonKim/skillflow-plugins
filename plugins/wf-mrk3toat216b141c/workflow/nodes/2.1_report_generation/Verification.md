## 验收项

- `outputs/` 中存在 UTF-8 编码的 `report-content.json`，且覆盖人生主基调、当前十年阶段、近三年年度趋势三部分。
- 依赖恢复日志或执行记录中包含实际使用的 npm registry；默认情况下为 `https://registry.npmmirror.com`，设置 `NPM_REGISTRY` 时为对应覆盖值。
- HTML 报告文件由 `Context/scripts/render-report.mjs` 生成，并且已使用上游星盘 JSON 中的基础信息、当前阶段和三年流年数据。
- HTML 报告文件以 UTF-8 读取时中文正文正常显示，不存在由编码替换产生的连续 `????`。
- 报告中的关键判断能够追溯到星盘 JSON 中的宫位、阶段或流年数据，且没有凭空补造星曜、宫位或年份信息。
- 报告可以少量使用必要紫微概念，但每处专业概念都已转译成现实含义，没有连续堆砌术语或庙旺陷等难读标签。
- 报告不包含绝对化宿命表达、具体事件预测、空泛鸡汤式鼓励或无法落地的套话。
- PNG 长图存在且由同一 HTML 文件渲染生成；若 PNG 不存在，产出中明确记录浏览器缺失或渲染失败原因。
- HTML 与 PNG 文件名使用同一时间戳前缀。
- 节点执行结束后已尝试打开 HTML 本地文件，最终汇报包含 HTML 路径与 PNG 路径或 PNG 失败原因。
