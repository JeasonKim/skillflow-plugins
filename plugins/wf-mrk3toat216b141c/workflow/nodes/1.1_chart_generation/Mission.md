## 职责

本节点负责把用户提供的出生信息归一化，并生成后续报告撰写所需的紫微星盘数据 JSON。

## 输入

- 用户在 task 需求中提供的姓名、性别、出生日期、出生时间、出生地等信息。
- 本节点 `Context/scripts/gen-chart.mjs` 排盘脚本。
- 本节点 `Context/` 根目录中的 `package.json` 与 `package-lock.json`。

## 执行要求

// 归一化出生信息

- 解析并校验用户提供的出生信息，至少需要性别、出生日期、出生时间和出生地。
- 如果用户提供农历日期，应先转换为阳历后再进入排盘。
- 如果出生时间是模糊时段，应选择该时段中间值作为近似值，并在产出中记录该近似依据。

// 完成真太阳时校正

- 根据出生地经度进行真太阳时校正，使用公式：`真太阳时分钟 = 标准时间分钟 + (当地经度 - 时区基准经度) × 4`。
- 中国大陆常规出生地默认以东八区、东经 120° 为基准；海外出生地应先明确当地时区，再落到当地真太阳时。
- 校正后若跨越日期边界，必须同步调整排盘日期。
- 将校正前时间、出生地经度、校正偏移、校正后时间、最终时辰与 `timeIndex` 写入产出。

// 恢复节点依赖

- 本节点不要求分发 `node_modules/`。
- 调用排盘脚本前，必须在本节点 `Context/` 内基于 `package-lock.json` 恢复 npm 依赖，默认命令为 `npm ci --ignore-scripts --registry=${NPM_REGISTRY:-https://registry.npmmirror.com}`。
- 如果运行环境不支持 shell 变量展开，应等价使用 `NPM_REGISTRY` 环境变量的值作为 registry；未设置时使用 `https://registry.npmmirror.com`。
- 依赖恢复失败时必须输出明确错误，包含失败命令、registry、缺失依赖或退出码；不得伪造星盘数据继续执行。

// 生成星盘数据

- 使用 `Context/scripts/gen-chart.mjs` 生成星盘 JSON。
- 脚本执行失败时必须输出明确错误，包含失败命令、输入参数摘要和退出码；不得伪造星盘数据继续执行。

## 产出

- 在本节点 `outputs/` 下输出结构化出生信息与校正记录。
- 在本节点 `outputs/` 下输出星盘数据 JSON，供下游节点读取。
- 产出中不得包含报告正文，只提供可追溯的排盘输入与排盘结果。
